# SkyOne Home · Propiedades

Página pública con las captaciones y los logros de la oficina SkyOne Home.

- Se actualiza sola cada 30 minutos desde el sistema de SkyOne (Actions → "Actualizar propiedades").
- Solo publica datos públicos: nada de emails, teléfonos, propietarios, catastro ni montos.
- Para editar el equipo, la fecha de apertura, las premiaciones o los asesores Club One: abrí `index.html` y buscá el bloque **DATOS DE LA OFICINA**.
- Para forzar una actualización: Actions → Actualizar propiedades → Run workflow.
